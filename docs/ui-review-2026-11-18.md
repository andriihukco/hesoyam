# UI review — 2026-11-18

Source: code read of `frontend/src` (App, Header, Positions, AlphaLog, Chats, Activity, StrategyConfig, Presets, Arena, PositionDetail).
Not verified visually yet: the dashboard needs the token from `.env`, which was not entered.

## Biggest problem: one sidebar does five jobs

The Strategy column (360–380 px on desktop) holds 13 groups in this order:
Arena · Presets · Mode · Telegram folders · RPC · Entry · Take-profit ladder · Exits · Entry timing · Signal filter · Risk & momentum · Limits · Reset paper wallet.

That mixes strategy parameters, performance (Arena), infrastructure (RPC, Telegram, mode) and a destructive action (reset).

**Fix:** split into pages.

| Tab | Contents |
|---|---|
| Positions | as today + status strip + today/all-time summary |
| Logs | Signals, Mentions, Chats, Activity (stats move out) |
| Strategies (new) | preset list with versions and performance, editor, compare, Arena |
| Agents (new, later) | agent runs, proposed versions, promotions, audit log |
| Settings (new) | Mode, Telegram folders, RPC, cost model (fees, tip, latency), reset wallet |

5 tabs fits the phone tab bar; desktop gets a left nav instead of the fixed 3-column grid.

## What works well

- Clear status strip (RPC ping, feed, Telegram, social) with colored dots and text, not color alone.
- Signals show per-check reasons and "entry delay cost": the best analytics hook in the app.
- Arena ranks by PnL, not win rate, and marks unqualified lanes. Correct choice.
- Position detail sheet: bottom sheet on phone, dialog on desktop, Escape closes.
- Theme tokens + light/dark, safe-area insets handled.
